
# Hangman Game

A desktop Hangman game developed with Java 25, JavaFX and Maven.

## Project Description

This project aims to develop a complete Hangman game while applying
nine software design patterns.

## Technologies

- Java 25
- JavaFX 27
- Maven
- Git and GitHub

## Design Patterns

The project will implement:

1. Singleton
2. Factory Method
3. Abstract Factory
4. State
5. Strategy
6. Observer
7. Proxy
8. Composite
9. Decorator

## How to Run

```bash
mvn clean javafx:run
```
